# DSE 香港史 論述題 知識卡片

手繪塗鴉風格知識卡片，全繁體中文。

圖片已上傳至 Google Drive 並設為公開可檢視。

此倉庫可用於 GitHub Pages 托管靜態網站。

## 使用 GitHub Pages
1. 進入倉庫 Settings > Pages
2. Source 選 Deploy from a branch
3. Branch 選 main / root
4. Save

網站位址將為：https://lmn-web.github.io/dse-history-knowledge-cards/

請將 index.html 上傳至此倉庫即可（圖片使用 Drive 公開連結）。
